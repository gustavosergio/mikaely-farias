# Mikaely Farias — Psicologia & Sexologia

Site: https://gustavosergio.github.io/mikaely-farias/

Site responsivo desenvolvido em React, TypeScript e Tailwind CSS. A raiz contém a versão estática compilada. O arquivo codigo-fonte.zip contém o projeto original com os componentes, estilos, fotos e configurações para desenvolvimento.

Para desenvolver: extraia codigo-fonte.zip, execute npm install e npm run dev. Para compilar: npm run build.

Fotos públicas: https://www.instagram.com/psimikaely/
